提审新手指南

发表于2025-11-11|更新于2026-03-17
|浏览量:

闲来无事记录下

  1. 进入抖音开发者平台

    1. 初始化准备
      1. 输入提供的账号密码登录
      2. 然后点击账号中心 - 成员协作 - 添加成员 - 添加要提审的游戏 - 成员用户名输入自己的英文名 - 权限给自己拉满 - 确认添加
      3. 然后登陆自己的账号 打开 抖音开发者平台 - 成员协作
      4. 点击接受邀请 - 确认接受
    2. 提审准备
      1. 登陆自己的账号 打开 抖音开发者平台 - 游戏管理
      2. 点击要提审的游戏 - 开发设置 - 配置域名 一般只用配置抖音的 游戏服务器的 DownLoadFile合法域名
      1. 设置 商业化-流量主
        1. 激励视频广告
        2. 插屏广告
    3. 获取三个数据(从上面拿)
      • APPID
      • VIDEOID
      • INSID

  2. 找源码

    1. 找到游戏的源码方式：
      1. 从对应游戏的 对标游戏 寻找
      2. 根据标签 寻找
      3. 谁发我的找谁要

  3. 修改源码

    1. 如果是js项目找到 DouyinSDK.js 文件，是ts项目则找到 AdMgr.ts 文件
    2. 替换上面获取到的三个数据
      • APPID
      • VIDEOID
      • INSID
    3. 修改资源文件
      1. 例如 提供给你的 UI 资源文件
    4. 打开侧边栏提示弹窗是 ChooseUI 内的 onClickRewardBtn 按钮
    5. 修改按钮绑定的 函数 一般是 sidebar.js 内的
      • openid 函数 绑定到绿色的小宠物图标按钮
      • navigate 函数 绑定到打开侧边栏的按钮
      • 如果两个图标都没有则需要自己创建这两个图标和侧边栏界面
      1. 在游戏的常驻按钮内添加一个空节点 命名为 Buttons
      2. 将sidebar.js 拖动到 Buttons 内
      3. 在 Buttons 内添加一个空节点 命名为 OpenID
        1. 在 OpenID 内添加一个按钮属性和 渲染 属性
        2. 将 Buttons 节点 拖动到 按钮 属性内
        3. 选择 openid 函数
      4. 在 Buttons 内添加一个空节点 命名为 openButtonShow
        1. 在 openButtonShow 内添加一个按钮属性和 渲染 属性
        2. 将 Buttons 节点 拖动到 按钮 属性内
        3. 选择 openButtonShow 函数
      5. 创建一个空节点 命名为 NavigateView
        1. 创建一个空节点 命名为 User-use
        2. 在 navigate 内添加一个按钮属性和 渲染 属性
        3. 将 Buttons 节点 拖动到 按钮 属性内
        4. 选择 navigate 函数

  4. 构建

    1. 在cocos creator 中 点击 项目 - 构建发布
      发布平台选择： 字节跳动小游戏
      Appid： 1-3获取到的 APPID
      其他默认即可
    2. 点击构建
    3. 构建完成后 会在项目目录下生成一个 E:\baoxiaogaicha\build 文件夹
    4. 使用 coscmd 上传将资源文件上传到游戏服务器
